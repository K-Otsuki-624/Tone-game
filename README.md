# ズレ音ハンター 🎵

ほんの少しだけ音程がズレた音を聴き分ける、音感トレーニングゲームです。
ブラウザだけで動きます（Web Audio API 使用・外部ライブラリなし）。

## モード

| モード | 内容 |
| --- | --- |
| **単音モード** | 同じ音が3回鳴ります。1つだけ少し高い／低い音が混ざっているので、何番目かを当てます。 |
| **フレーズモード** | 短いメロディーの中で1音だけ音程がズレています。楽譜の音符をタップして当てます。 |

## 難易度

| 難易度 | ズレの大きさ |
| --- | --- |
| 初級 | 30〜50 セント |
| 中級 | 10〜30 セント |
| 上級 | 5〜10 セント |

（半音 = 100 セント）。1回のプレイは全10問で、ベストスコアはブラウザに保存されます。

## 収録フレーズ

きらきら星／かえるの合唱／ちょうちょう／メリーさんのひつじ／喜びの歌／ロンドン橋／聖者の行進／ジングルベル／ふるさと／さくらさくら／蛍の光／家路／ハッピー・バースデー／アルプス一万尺／メヌエット ト長調　＋ オリジナル6曲

すべてパブリックドメインの楽曲、またはこのゲームのためのオリジナルです。
曲の追加は `js/melodies.js` に書式どおり1行足すだけでできます。

## GitHub Pages で公開する

1. このブランチを `main` にマージする
2. リポジトリの **Settings → Pages** を開く
3. **Source: Deploy from a branch**、**Branch: `main` / `(root)`** を選んで Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

ローカルでは `index.html` をブラウザで開くだけで動きます。

## ファイル構成

```
index.html        画面
style.css         スタイル（ライト／ダーク対応）
js/audio.js       音源（Web Audio）
js/score.js       五線譜の SVG 描画
js/melodies.js    フレーズ集
js/app.js         ゲーム進行
```
